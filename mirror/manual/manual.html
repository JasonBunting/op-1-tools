Your OP-1's screen, big.

OP-1 Mirror shows the OP-1's screen live on a Windows PC or an Android phone, so you can read detailed screens from across the room while your hands stay on the machine. Every screen mirrors, stock or plugin.

How it works

A small plugin on the OP-1 sends the parts of the screen that changed over the USB cable, as MIDI. The viewer on the PC or phone draws them. The OP-1 only sends while a viewer is listening, and stops within about three seconds of the viewer closing.

It doesn't know or care what's on the screen, so every mode, every plugin and every menu mirrors the same way. It runs at about 40 frames a second with no effect on the sound.

What you need

  1. An original OP-1 running Hundekraft (3.3, 3.2.3 or 3.1.4).
  2. Windows 10 or 11 (64-bit), or an Android 8 or later phone with USB-C.
  3. From the Releases page: mirror.knl (the plugin) and the viewer for your device, Op1Mirror.exe or op1-mirror.apk. Nothing needs building; the Mirror README covers building from source.

Get started

First, put the plugin on the OP-1: in the Hundekraft workshop, open Your plugins, add mirror.knl, choose Review changes, then Send to OP-1, and press T1 on the OP-1 to confirm. You only do this once.

On Windows

  1. Close the browser completely, every window. Windows lets only one program at a time use the OP-1's MIDI connection, and the workshop page holds on to it.
  2. Plug in the OP-1 and run Op1Mirror.exe.
  3. The OP-1's screen appears. There is nothing to switch on on the OP-1: it starts sending when the viewer asks.

Pull the cable and plug it back in, and the viewer reconnects by itself.

On an Android phone

  1. Install op1-mirror.apk. Android asks you to allow installs from unknown sources the first time.
  2. Plug the OP-1 into the phone with a USB-C OTG cable or adapter. Android asks whether OP-1 Mirror may use the device: allow it.
  3. The OP-1's screen appears. Tap the screen to show or hide the controls; they are the same as on Windows.

The viewer

Both viewers remember their settings between launches. On Windows that includes the window's size and place, kept in %LOCALAPPDATA%\Op1Mirror\settings.json; delete that file to go back to the defaults.

Settings

The defaults suit most screens. Change them if the picture lags or breaks up.

SettingDoes
Budget (Auto)How much the OP-1 may send at a time. Auto raises it slowly and backs off if anything is lost or the OP-1 slows down. Leave it on Auto
ScanHow much of the screen the OP-1 checks for changes each time round. Higher shows changes sooner
RefreshHow much of the screen is resent each time round even if unchanged, so anything lost mends itself
Whole framesShows only complete pictures. On very busy screens (such as Strings) this stops parts of two pictures showing at once, at fewer pictures per second
Palette / RLE tilesWays of packing the picture. The plugin picks the smallest each time. Leave both on
Whole-number zoomScales by exact multiples, so every OP-1 pixel is an even square

Keys (Windows)

KeyDoes
F11Fullscreen, with the controls hidden
EscLeaves fullscreen
TKeeps the window on top of others

If it doesn't connect

  1. "The OP-1 is busy": another program has its MIDI connection. Close every browser window (the workshop is the usual one), and any music software, then start the viewer again.
  2. The viewer connects but stays blank: check that mirror is listed as installed in the workshop, and that the OP-1 was restarted after installing it.
  3. Tape input level keeps changing: the viewer uses MIDI channel 16. On the OP-1's COM screen, leave PARAM CH off, or on a channel other than 16.
  4. The picture tears on busy screens: turn on Whole frames.
Note

The plugin uses a fixed place in the OP-1's firmware. It's built for Hundekraft 3.3 and checked on the device on 3.2.3 and 3.1.4; a newer Hundekraft may need a new build.

Limits

  1. One viewer at a time.
  2. Windows and Android only. An iPhone viewer is possible but nobody has made one; the README says what it would take.
  3. The mirror shows the screen only: no sound, and no control of the OP-1 from the viewer.
