What's on the OP-1

Reads the plugin inventory and the switched-off list over USB MIDI, with the Hundekraft workshop's own protocol code. Reading changes nothing; the switched-off list is saved only when you press its button. Close the workshop tab first: only one page can talk to the OP-1.

Switch plugins off

Names from the Name column, separated by commas. They stay installed but don't load from the next restart of the OP-1. Empty the box and save to switch everything back on.
