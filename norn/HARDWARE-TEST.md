# Norn: hardware check (0.5.2)

0.5.2 replaces the placeholder figures with Astra's three keepers. Nothing else changed. Install `build/norn.knl` and
open Norn's engine screen (T1).

1. Look at the keepers.
   - Expect: three blue hooded figures on the left, faces with dark openings, no stray lines or triangles joining
     parts of them, and each thread starting at a hand. The screen opens as quickly as before.
2. With the screen showing, on wave terrain (green about 60%, white right, orange middle), open the monitor and read
   **synth** and **pk** with six keys held.
   - Expect: about the same as before (31 / 59). A screenshot from OP-1 Mirror would help too.

Report anything that looks wrong, plus the two numbers.
